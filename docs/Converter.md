# Converter で Proxy Excel を作成する

Converter は、神Excel から Proxy Excel を作成する画面のプログラムです。この文書では、Proxy を作成し、Excel で見出し名を確認・修正して確定するまでの手順を説明します。

Converter は、スタートメニューの「Daten」フォルダーにある「Daten Converter」から起動します。

## 1. 入力を準備する

`.xlsx` の神Excel を用意します。`.xlsm` は扱えません。行見出し（表の左側）と列見出し（表の上側）の両方が必要です。1シートにつき1組の領域を指定します。行見出しのない帳票や、同じシートに複数の表がある帳票は対象外です。

入力ブックに Excel のテーブルがあると、非表示のシートや変換しないシートにあるものも含めて、読込みが拒否されます。表示されたシートとテーブルを確認し、参照関係を調べたうえで、ブックのコピーを作り、そのコピーで Excel の「範囲に変換」を行ってから再実行してください。Converter がテーブルを自動で削除することはありません。

## 2. 入力を選び、推定された範囲を確認する

「入力ファイルを選択」で神Excel を開きます。

各シートの見出し領域が自動で推定されます。推定できなかったシートは手入力してください。入力ファイルと同じフォルダーに同じ名前の `.daten.json`（例：`帳票.xlsx` に対して `帳票.daten.json`）があると、推定の代わりにその設定が読み込まれます。設定が正しくない場合はエラーになり、推定には切り替わりません。

「シート」で編集するシートを選び、行・列の見出し領域を確認します。必要に応じて、シート選択欄の右の「見出し領域を自動推定」を押し、結果を修正します。どちらかの見出し欄に入力がある場合は、置き換えてよいかの確認が表示されます。推定結果は入力の補助です。正しい表を選んでいるかは、利用者が確認してください。

シート一覧には名前だけが表示され、非表示のシートかどうかは表示されません。必要なら元の Excel で確認してください。

## 3. 対象シートと領域を指定する

| 入力欄 | 指定する場所 | 例 |
|---|---|---|
| 列見出し領域（表の上側） | データ列を説明する複数段の見出し | `D1:Y13` |
| 行見出し領域（表の左側） | データ行を説明する複数列の見出し | `A14:C50` |

この例のデータ領域は `D14:Y50` です。生成される列見出し名は `D13:Y13` に、行見出し名は `C14:C50` に書かれます。列見出しの下端の次の行から行見出しが始まり、行見出しの右端の次の列から列見出しが始まるように指定してください。

範囲は `開始セル:終了セル` で入力します。単一セルも `A1:A1` と指定できます。シート名付きの参照、複数の範囲、行全体・列全体の指定は使えません。

すべてのシートを確認してください。**両方の欄が空のシートは変換の対象外**です。変換しないシートに推定値が入っている場合は、両方の欄を空にします。片方だけ空にすると、生成時にエラーになります。シートを選ぶだけでは、変換の対象は変わりません。

入力の検証は、生成を押したときに行います。データ領域と見出し名の書込み先は画面に表示されないため、上の配置の規則と元の Excel を照らし合わせて確認してください。

## 4. 出力先を指定して生成する

「出力ファイルを選択」で、入力とは別の `.xlsx` を指定します。たとえば `帳票.xlsx` に対して `帳票_proxy.xlsx` とします。

出力ファイルの初期候補は、入力と同じファイル名になっています。保存先と名前を必ず確認して変更してください。入力と同じファイルへの出力は拒否されます。既存のファイルを選んだ場合は、上書きの確認が表示されます。

「Proxy Excelを生成」を押すと、対象のすべてのシートの領域を検証してから生成します。処理中は、終わるまで待ってください。

成功すると、出力先、対象シートの見出しの件数、警告などがメッセージ欄に表示されます。メッセージは選択してコピーできます。

## 5. エラー・警告に対処する

| 状況 | 確認・対処 |
|---|---|
| 入力の読込み失敗 | メッセージのパスと原因を確認する。以前の入力が残っている場合は、いま扱っているブックを確認する |
| 設定（`.daten.json`）の読込み失敗 | シート名・領域・形式を確認する。推定に戻ったとは考えない |
| 領域のエラー | 両方の領域があるか、長方形か、隣り合っているかを確認する。対象外にするなら両方の欄を空にする |
| 数式・結合のエラー | 見出し領域に数式を含めていないか、結合セルが領域の境界をまたいでいないかを確認する |
| 見出し名の重複 | 重複した名前のすべてに `_1`、`_2`… が付いて生成される。警告のセル番地と仮の名前を確認し、確定前に意味のある一意な名前に直す |
| dummy 名の警告 | 空の見出し名が補われている。生成後に Excel で確認・修正する |
| テキスト枠のフォントの警告 | テキスト枠の文字が、隣の列の名前に入っている可能性がある。生成された名前を確認する（[既知の問題](KnownIssues.md)を参照） |
| テーブル生成の警告 | テーブルが作られなかった Proxy は Bridge で使えない。警告の内容を確認し、帳票のコピーを整えて再生成する |
| 保存の失敗 | 出力先のパス、権限、他のアプリで開いていないかを確認し、解消してから再実行する。失敗したときの出力は使わない |

エラーのあるシートは、自動では除外されません。修正して再生成すると、改めて検証されます。複数のシートにエラーがある場合、最初のエラーだけが表示されることがあります。

## 6. Excel で Proxy を確認し、見出し名を確定する

保存した Proxy を Excel で開き、見出し名が元の帳票の意味に合っているかを確認します。必要な行・列の見出し名を修正して保存します。重複を区別するために付いた `_1`、`_2`… は仮の名前です。番号を付けても、欠けた見出しの文字は戻りません。確定前に、意味のある一意な名前に直してください。

見出し名の確認と修正は、確定前の通常の作業です。確定した後の Proxy は、プログラムがデータを更新するためのものです。人が作業する場所としては使わないでください。手作業でデータを直すなら、神Excel を直接編集してください。確定した後に見出し名を変えたくなった場合は、Proxy を作り直して、確認・確定し直します。

見出し名を直すときは、Excel のテーブルの列名と見出しセルの文字を一致させてください。Bridge は使う前に、テーブルの列名と見出しセルの一致や、行・列の見出し名に空白や重複がないかを検査します。また、Proxy には Daten が使う管理情報（Custom XML）が含まれています。見出し名の修正と保存には Excel を使ってください。ほかのツールで保存すると、管理情報が失われることがあります。

元の神Excel は変更されません。Proxy のデータ・数式・変換しなかったシートも確認してください。見出しの行の高さや列の幅をまとめる処理は行・列全体に作用するため、同じ行・列にある変換対象外のセルの表示が変わることがあります。

確定した Proxy の使い方は、[Bridge のガイド](Bridge.md)と [Python のガイド](Python.md)を参照してください。

## 7. ヘルプを確認する

「ヘルプ」から、最新版と説明資料、Webサイト、使用許諾契約、第三者ライセンス、特許出願番号、バージョン情報（使用期限を含む）を確認できます。法務文書は全文を選択してコピーできます。使用期限のメッセージが出た場合は、表示内容を確認し、「最新版と説明資料」から最新版を入手してください。
