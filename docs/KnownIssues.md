# Daten 0.8.0 の既知の問題と制限

Daten 0.8.0 で分かっている問題と制限、その回避方法をまとめます。どの場合も、元のファイルのコピーで作業し、結果を確認してから使ってください。

<!-- 内部管理用：各項目の末尾のコメントは、docs/quality/KnownIssues.md の ID との対応です。 -->

## 1. 再計算

- **proxy-to-kami・embed の後、数式の計算結果が古いまま残ります。** Daten は再計算しません。定数が更新されても、数式の計算結果とグラフに保存された値は古いままです。提出・配布・集計に使う前に、Excel で出力を開き、Ctrl+Alt+F9 で再計算して保存し直してください。詳しくは [Bridge のガイド](Bridge.md#再計算に関する-080-の既知の制限)を参照してください。<!-- S4-01 -->
- **kami-to-proxy は、神Excel に保存されている計算結果をそのまま転記します。** 神Excel が再計算済みかどうかは確認しません。実行前に神Excel を Excel で再計算して保存してください。<!-- S4-01 / DECISION-12 -->

## 2. Converter で扱えない、または注意が必要な帳票

| 帳票の状態 | 起きること | 回避方法 |
|---|---|---|
| Excel のテーブルを含む | 読込みが拒否される | コピーで参照関係を確認し、Excel の「範囲に変換」で解除してから再実行する |
| `.xlsm` | 読込みが拒否される | マクロを除いた `.xlsx` のコピーで Proxy を作る。ただし、元の `.xlsm` と組み合わせる手順は保証していない |
| 配列数式・動的配列（スピル）・データテーブルの結果が見出しの範囲にかかる | 見出しの書換えで、数式の結果の範囲に文字が書き込まれることがある | これらの結果の範囲を、見出し領域に含めない <!-- D-02 / S2-04 --> |
| データ領域に複数セルの配列数式がある | テーブルが作られることがあり、Excel で開いたときの動作は未確認 | このような帳票は Converter で使わない <!-- S2-05 --> |
| 見出しのセルを、ほかのシートの数式・名前の定義・入力規則などが参照している | 見出し名の書換えで、参照先の意味が変わることがある。生成前には検出しない | 参照関係のある帳票は、事前にコピーで確認する <!-- S2-03 --> |
| 行見出しの列と列見出しの行が交わる左上の角が結合されている | テーブルが作られないことがある | コピーで角の結合を整理して再生成する。警告とテーブルの有無を確認する <!-- S2-06 --> |
| 結合セルの内側に罫線や値が残っている（Excel 以外のツールで作ったファイル） | 見出しが分かれて親の名前が欠けたり、画面に見えない値が名前に入ったりする | コピーを Excel で開き、結合の内側の罫線や値を整理して再生成する <!-- S2-02 / S6-03 --> |
| 見出しの行・列が非表示になっている | 非表示の部分の文字も名前に入る | 生成前に非表示の部分を確認し、確定前に名前を確認する <!-- S2-10 --> |
| 見出しが数値・日付・真偽値 | 表示されている文字ではなく内部の値（日付ならシリアル値）が名前になる。「.」の除去で小数点も消える | コピーで見出しを文字列にしてから生成する <!-- S4-02 --> |
| 罫線を、行全体・列全体の書式だけで付けている | 見出しの区切りとして認識されない | コピーで、対象のセルに罫線を直接設定する <!-- S6-02 --> |
| 行見出しの列に列幅の指定がなく、シートの既定の列幅もない | 生成に失敗する | コピーで、その列に列幅を指定する <!-- S3-06 --> |
| 見出しにテキスト枠（テキストボックス）がある | 標準フォントによっては、枠の文字が隣の列の名前に入ることがある。該当するときは警告が出る | 生成された名前を確認し、枠の文字が正しい列に入っているかを照合する <!-- S2-01 / MDW --> |
| 見出しの文字に改行がある | 確定後の Bridge の処理で拒否される可能性がある | 確定前に、改行のない名前に直す <!-- S2-08 / S3-05 --> |

このほか、次の点に注意してください。

- 重複した見出し名には `_1`、`_2`… が、空の見出し名には dummy 名が付けられます。確定前に、意味のある一意な名前に直してください。<!-- F-19 -->
- 見出しの行の高さや列の幅をまとめる処理は行・列全体に作用するため、同じ行・列にある変換対象外のセルの表示が変わることがあります。<!-- GUI-08 -->

## 3. Converter の画面

- 出力ファイルの初期候補が入力と同じ名前になります。保存先と名前を必ず変更してください。<!-- UI-01 -->
- シート一覧に、非表示のシートかどうかが表示されません。<!-- UI-02 -->
- 手入力した領域から導かれるデータ領域と、見出し名の書込み先が表示されません。<!-- UI-03 -->
- 複数のシートにエラーがある場合、最初のエラーだけが表示されることがあります。英語や内部のメッセージがそのまま表示されることもあります。メッセージをコピーして保存し、入力のコピーで原因を切り分けてください。<!-- UI-04 / S4-04 / S3-03 -->
- 処理中の進み具合は、シートや段階ごとには表示されません。<!-- UI-06 -->

## 4. Bridge・Python

- 神Excel と Proxy は、同じセル番地どうしで対応します。行・列の移動や並べ替え、帳票の改訂には追従しません。
- proxy-to-kami は、変更したセルだけでなく、対応するすべての定数を同期します。同時に更新されても検出しません。
- グラフシートなど、ワークシート以外のシートは処理の対象外です。
- データ領域にかかる配列数式・データテーブル・動的配列があると、処理が拒否されます。
- データセルの書式は、数値の表示形式と日付体系だけを比較します。色・罫線・フォントだけを変えた様式の改訂は検出しません。<!-- DECISION-13 -->
- 他のプログラムで開いているファイルは処理できません。閉じてから再実行してください。
- OneDrive の「オンラインのみ」のファイルなどは、処理が拒否されます。同期フォルダーの外にある、通常のローカルのコピーで処理してください。<!-- S6-07 -->
- 転記で値を変えた文字列セルの、ふりがなと文字ごとの書式（リッチテキスト）は失われます。<!-- S6-05 -->
- セル内の画像や特殊なデータ型を含むセルに値を転記すると、画像やデータ型と値が食い違うことがあります。そのようなセルを含むテーブルの転記は避けてください。<!-- S6-06 -->
- 変更するセルが非常に多いと、保存後の検証に時間がかかります。<!-- S4-03 -->
- 強制終了などで処理が途中で止まると、`.daten-` で始まる一時ファイルが残ることがあります。処理が終わったことを確認してから削除してください。<!-- S4-06 -->
- Python で、Bridge の処理は成功したのに、その後の Python 側の処理で例外になった場合、出力ファイルが残ります。再実行するときは、別の出力先を指定してください。<!-- S4-05 -->
- Python の辞書風 API で、大文字と小文字だけが異なるテーブル名を指定すると、別々のものとして扱われます。同じセッションでは表記をそろえてください。<!-- S3-09 -->

## 5. 評価版の使用期限

0.8.0 は評価版で、使用期限は 2027年1月31日です。期限の当日までは使えます。2027年1月1日からは、更新の案内が表示されます。

期限を過ぎると、Converter での Proxy の生成と、Bridge の kami-to-proxy・proxy-to-kami・embed（dry-run を含む）が拒否されます。Converter の起動とヘルプの表示、extract によるデータの読出し、作成済みのファイルの利用はできます。最新版は、このリポジトリのリリースから入手してください。
