# 使用例

[基金の状況](fund/README.md)：Python で定数を設定し、神Excel への転記、Excel での再計算・保存、数式キャッシュの転記と読出しまでを行う往復例です。実行手順はリンク先を参照してください。

このフォルダーのサンプルは、[LICENSE](LICENSE)に定めるMITライセンスで提供します。自分のプログラムの元にするなど、自由に使ってください。サンプルから呼び出すConverterとBridgeには、使用許諾契約が適用されます。

`fund/kami.xlsx` と `fund/proxy.xlsx` は、総務省「地方財政状況調査」の第97表（基金の状況（復旧・復興事業分））の様式をもとに作成したものです。値はすべて架空のもので、実在の団体の決算の数値ではありません。MITライセンスは、当社が作成した部分（スクリプト、値、Proxy Excelへの変換結果など）に適用されます。
