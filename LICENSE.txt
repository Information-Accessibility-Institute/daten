Daten（堕天）ソフトウェア使用許諾契約
制定日：2026年10月20日　第1版

第1条（適用範囲および契約への同意）
1. 本契約は、合同会社情報アクセシビリティ機構（以下「権利者」といいます。）が提供するDaten（堕天）のConverter、Bridgeおよびこれらに付随するソフトウェア（以下「本ソフトウェア」といいます。）の使用に適用されます。
2. 本ソフトウェアには、正式版ならびに開発版、評価版その他の試用版が含まれます。
3. 本ソフトウェアは実行形式で提供され、ソースコードは公開されません。ただし、第7項のPythonクライアントを除きます。
4. 利用者は、本ソフトウェアの使用を開始する前に、本契約の内容を確認し、これに同意するものとします。
5. 本契約に同意しない場合、利用者は本ソフトウェアを使用することができません。
6. 本契約に基づく使用許諾は、非独占的かつ譲渡不能なものとします。
7. 本ソフトウェアに同梱するPythonクライアント（pythonフォルダーに含まれるdatenパッケージ）は、同フォルダーのLICENSEに定めるMITライセンスにより提供し、本契約は適用しません。ただし、Pythonクライアントから呼び出すConverterおよびBridgeの使用には、本契約が適用されます。

第2条（定義）
本契約において、次の用語は以下の意味を有します。
1. 自己利用：利用者自身の業務、研究、教育その他の活動のために本ソフトウェアを使用することをいいます。営利目的であるか否かを問いません。第三者から受託した業務の遂行、または第三者向けの製品・サービスの開発・提供のための使用は、利用者の社内で行う場合であっても、自己利用には含みません。
2. 受託利用：利用者が第三者から委託を受け、当該第三者のために行う業務の遂行に本ソフトウェアを使用することをいいます。顧客の帳票の解析、システムの設計・開発、試験および保守のための使用を含み、本ソフトウェア自体を顧客に納品するかどうかを問いません。
3. 第三者提供利用：第三者向けの製品またはサービスに本ソフトウェアを組み込み、または本ソフトウェアの機能を第三者に提供することをいいます。
4. 小規模事業者：直近の確定事業年度における年間売上高が1億円未満の事業者であって、第5条に定める除外条件に該当しないものをいいます。
5. 有償利用：第4条の規定により、権利者との個別の有償使用許諾契約を必要とする利用をいいます。

第3条（無償利用）
1. 利用者は、自己利用のために本ソフトウェアを無償で使用することができます。
2. 前項は、個人、民間企業、大学、研究機関、地方公共団体、国の行政機関その他の法人または団体のいずれにも適用されます。
3. 自己利用には、本ソフトウェアの繰り返しの使用、大量のスプレッドシート文書の処理、自動実行、および他のプログラムからの呼出しを含みます。
4. 利用者が自らの業務のために第三者から受領したデータを処理する場合であっても、第2条第2号の受託利用または同条第3号の第三者提供利用に該当しない限り、自己利用とします。
5. 小規模事業者は、受託利用および第4条第3項に定める第三者向けサービス提供についても、無償で本ソフトウェアを使用することができます。ただし、第6条に定める表示義務に従うものとします。
6. デジタル庁は、国の行政機関および地方公共団体の業務のために、本ソフトウェアを無償で使用することができます。ただし、デジタル庁から業務を受託した事業者による利用については、その事業者自身に本契約を適用します。
7. 北海道、北海道内の市町村または藤沢市を最終的な提供先とするソフトウェアの納品、業務の受託またはサービス提供のために本ソフトウェアを使用する場合は、第4条第1項および第2項の規定にかかわらず、無償で使用することができます。この無償利用は、利用者の所在地、規模、当該地方公共団体との契約件数、および関係する部署の数にかかわらず適用されます。
8. 前項の無償利用には、北海道が道内市町村に提供するサービス、および北海道内の市町村が共同して利用するサービスのための使用を含みます。
9. 同一の事業またはサービスに第7項の対象となる最終的な提供先とそれ以外の提供先が含まれる場合、同項の無償利用は、対象となる提供先向けの利用に限り適用します。それ以外の提供先向けの利用については、本契約の他の規定に従います。
10. 利用者が、派遣労働者を自らの指揮命令の下で自らの業務に従事させ、本ソフトウェアを使用させる場合は、当該利用者の自己利用として扱います。派遣元事業者が別途業務を受託し、本ソフトウェアを使用して当該業務を代行する場合は、受託利用として扱います。

第4条（有償利用）
1. 小規模事業者に該当しない事業者が受託利用を行う場合には、権利者との別途の有償使用許諾契約を必要とします。
2. 小規模事業者に該当しない事業者が第三者提供利用を行う場合にも、別途の有償使用許諾契約を必要とします。
3. 小規模事業者の第三者提供利用については、当該事業者自身が本ソフトウェアを実行してサービスを提供する場合に限り、無償で認めます。ただし、本ソフトウェアの実行ファイルを第三者に再配布し、または第三者に直接使用させる場合には、事業規模にかかわらず権利者の別途の許諾を必要とします。
4. 有償使用許諾契約の料金、期間、対象業務、利用範囲、保守、技術支援その他の条件は、個別契約により定めます。
5. 権利者が別途同意しない限り、本条に定める有償利用を開始する前に、個別契約を締結しなければなりません。
6. 本契約に基づく無償利用の資格を有することは、権利者から保守、技術支援、改修その他のサービスを無償で受ける権利を意味しません。

第5条（小規模事業者の除外条件および資格喪失）
1. 年間売上高が1億円未満であっても、以下のいずれかに該当する事業者は、第3条第5項の小規模事業者に含まれません。
   (1) 年間売上高が1億円以上の事業者が、単独で議決権の50%以上を保有する事業者
   (2) 年間売上高が1億円以上の複数の事業者が、合計で議決権の3分の2以上を保有する事業者
   (3) 年間売上高が1億円以上の事業者によって、直接または他の事業者を通じて実質的に支配される事業者
2. 前項の支配関係には、子会社、孫会社その他の間接的な支配関係を含みます。
3. 第1項の支配関係は、議決権の直接保有割合のみで判断せず、支配される事業者を通じた議決権の保有および経営支配関係を考慮します。
4. 複数の事業者が共同で支配する場合も、第1項の条件に従って判断します。
5. 個人事業主については、年間売上高に代えて、直近の暦年における事業収入を基準とします。
6. 直近の確定事業年度が存在しない新設事業者については、利用開始時点の事業計画に基づく初年度の年間売上高見込額を基準とします。ただし、第1項の除外条件は適用されます。
7. 年間売上高の増加により小規模事業者の資格を喪失した場合、資格喪失前に開始した受託業務については、資格喪失から1年間、引き続き無償で使用することができます。
8. 前項の期間中であっても、資格喪失後に新たに開始する受託利用または第三者提供利用については、第4条を適用します。
9. 合併、買収、株式取得その他の資本関係の変更によって第1項の除外条件に該当することとなった場合には、第7項の経過措置は適用せず、変更後の新たな受託利用または第三者提供利用について第4条を適用します。
10. 小規模事業者の資格喪失時期は、売上高については当該事業年度の売上高が確定した日、資本関係については当該変更の効力発生日とします。

第6条（小規模事業者による利用表示）
1. 第3条第5項に基づき、受託利用または第三者向けサービス提供を無償で行う小規模事業者は、自社のWebサイト、サービス紹介資料、営業資料その他の適切な媒体において、Daten（堕天）を利用している旨を表示するものとします。
2. 表示方法は、利用者が合理的な範囲で選択することができます。
3. 権利者への事前申請、利用実績の報告および表示実績の提出は必要ありません。
4. 本条に定める表示義務は、自己利用のみを行う利用者には適用されません。
5. 表示義務の不履行があった場合、権利者は当該事業者に是正を求めることができます。
6. 第5条第7項に基づく経過措置の適用期間中も、本条の表示義務は継続します。

第7条（評価目的の利用）
1. 有償利用を予定する事業者は、本ソフトウェアの機能、性能、適合性および導入可能性を評価する目的に限り、無償で使用することができます。
2. 評価利用には、実際の帳票を使用した検証、試験環境での自動実行、変換結果の確認その他導入判断に必要な行為を含みます。
3. 評価利用の期間は、原則として最初の評価利用開始日から3か月間とします。ただし、権利者が別途延長を認めた場合を除きます。
4. 評価利用の名目で、第三者に対する継続的な本番サービスを提供することはできません。
5. 本条は、第3条に基づいて無償利用できる者の使用期間を制限するものではありません。
6. 評価期間は、ソフトウェアのバージョンを変更したことのみを理由として新たに開始されるものではありません。

1. 本ソフトウェアのソースコードを取得することを目的とした逆コンパイル、逆アセンブルその他の解析行為
2. 本ソフトウェアの改変または改変版の配布
3. 本ソフトウェアの実行ファイルの無断再配布、貸与、販売または再使用許諾
4. 試用版に設定された実行期限その他の技術的制限の不正な回避
5. 本契約の無償利用条件に該当しないにもかかわらず、個別の有償使用許諾契約を締結することなく、第4条に定める有償利用を行う行為

1. 本ソフトウェアを使用して生成、変換または更新されたスプレッドシート文書、CSVファイルその他の出力データについて、権利者は、本ソフトウェアを利用したという事実のみを理由として権利を主張しません。

4. 本ソフトウェアの使用許諾が終了した場合も、適法な使用期間中に生成された出力データの利用は制限されません。

第14条（使用許諾の終了）

4. 使用許諾の終了は、適法な使用期間中に生成された出力データの利用を制限するものではありません。
